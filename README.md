# Huda Auto Parts

A dependency-free HTML, CSS and JavaScript storefront prototype.

## Run locally
Open `index.html` in a browser, or run `python -m http.server 8000` in this folder and visit http://localhost:8000.

## Publish on GitHub Pages
1. Extract the ZIP.
2. Upload the contents of this folder to the root of your GitHub repository and commit.
3. Open repository Settings > Pages.
4. Under Build and deployment select Deploy from a branch, then main and / (root). Save.
5. Use the URL displayed by GitHub Pages after deployment.

The site uses hash navigation (e.g. `#parts`) so direct links work on static hosting without server routing.

## Features and limitations
Search, category and condition filters, sample vehicle fitment, persistent local cart, demo checkout, quote and wholesale forms, account demo. All product data and USD prices are illustrative. Illustrations are SVG placeholders. No backend, real authentication, payments, email delivery, taxes or shipping integration. Do not enter real customer data. Verify actual fitment before selling parts.
